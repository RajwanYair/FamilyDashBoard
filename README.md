# Family Dashboard

A single-page family dashboard designed for always-on display in the main living room.

## Features

- **Real-time Clock** — Hebrew & English dates, time-of-day greeting
- **Weather** — Current conditions & 4-day forecast for Jerusalem (Open-Meteo API)
- **News** — Hebrew RSS feed from Rotter
- **Family Calendar** — Embedded Google Calendar (agenda view)
- **Stocks** — Live tracking: INTC, S&P 500, Bitcoin, NVDA, VIX, PLTR with trend charts
- **Daily Fact** — Random interesting fact translated to Hebrew

## Design

- Dark glassmorphism theme optimized for TV/large screens
- Auto-refresh every 5 minutes
- Responsive layout (TV → tablet → mobile)
- Emoji-based weather icons
- Sync status indicators per section

## Usage

Simply open `BestDashBoard.html` in any modern browser. No build step or server required.

Set the browser to full-screen (F11) for the best experience.
